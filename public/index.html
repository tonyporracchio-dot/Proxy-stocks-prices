Stock Price Proxy API

Endpoint per il recupero dei prezzi in tempo reale via Yahoo Finance

V1.2 / Static Home

Panoramica del Servizio

Questo server agisce come un proxy sicuro tra la tua applicazione front-end e Yahoo Finance. Interroga i dati finanziari in tempo reale tramite la libreria yahoo-finance2 e li restituisce in formato JSON, gestendo CORS ed eventuali errori di connessione.

Stato Server: Online

1. Come utilizzare l'API

Effettua una richiesta GET all'endpoint /price specificando i simboli (ticker) separati da virgola nel parametro di query symbols.

GET /price?symbols=TSLA,SWDA.MI

Il server inoltrerà la richiesta a Yahoo Finance e restituirà un oggetto JSON contenente un array di risultati.

2. Esempi di Risposta (JSON)

Successo (singolo titolo)

{
  "results": [
    {
      "symbol": "AAPL",
      "price": 175.43,
      "currency": "USD",
      "changePercent": 0.852
    }
  ]
}

Successo (multiplo - misto valuta/ETF)

{
  "results": [
    {"symbol": "GOOGL", "price": 150.20, "currency": "USD", "changePercent": -0.12},
    {"symbol": "SWDA.MI", "price": 98.55, "currency": "EUR", "changePercent": 0.45}
  ]
}

Come ricercare i Ticker

Il sistema utilizza la nomenclatura ufficiale di Yahoo Finance. Per trovare il ticker corretto:

  1. Vai su Yahoo Finance Lookup.
  2. Digita il nome dell'azienda o del fondo (es. "iShares Core MSCI World").
  3. Identifica il simbolo corretto.
    • Azioni USA: AAPL, MSFT.
    • Azioni Italiane: ENI.MI, RACE.MI.
    • ETF su Borsa Italiana: SWDA.MI, EUNL.DE.
    • Criptovalute: BTC-EUR, ETH-USD.
  4. Utilizza quel simbolo esatto nel parametro symbols=. Importante: Assicurati di includere i suffissi di mercato corretti (es. .MI per Milano, .DE per XETRA).

Nota: La ricerca del ticker su Yahoo Finance è il metodo più affidabile per assicurarsi che il proxy restituisca i dati corretti.
